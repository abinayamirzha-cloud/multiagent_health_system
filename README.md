# multiagent_health_system
Multi-Agent Healthcare Diagnosis System — An AI-based system that analyzes chest X-rays, patient symptoms, and lab reports using VGG16, ClinicalBERT, and XGBoost agents. It combines their results using hybrid optimization to predict diseases, assess severity, generate treatment suggestions, and recommend doctors and hospitals.
